# 【実装】【テスト】単体テストの `.claude/scripts/test/` への移動（issue #63）

全体作業計画: `plans/nested-exploring-cloud.md`

移動と参照更新は機械的で、テストの合否がそのまま回帰の判定になるため、実装とテストを
1ファイルへ併記して合意を1回で取る。

## 手順

1. `git mv` で4本を `.claude/scripts/test/` へ移動（履歴保持）。`tests/` は廃止。
2. 各テストの `repo_root` を `$script_dir/..` → `$script_dir/../../..` へ。
   冒頭コメントの `実行: bash tests/...` と `shellcheck source=../.claude/...` の相対パスも更新。
3. テスト対象スクリプト側のコメント4箇所のパス参照を更新
   （`extract-frontmatter.sh` / `update-handoff-progress.sh` / `vcs/Provider.sh` /
   `post-push-usage-report.sh`）。
4. `bash -n` ＋4本の実行で、移動前のベースラインと `passed` の内訳が一致することを確認。

## 判定基準（移動前ベースライン）

| ファイル | passed |
|---|---|
| `test_extract_frontmatter.sh` | 17 |
| `test_update_handoff_progress.sh` | 15 |
| `test_usage_tracking.sh` | 33 |
| `test_vcs_provider.sh` | 36 |

いずれも `failures=0`・終了コード0。**アサーションは1件も変更しない**ため、内訳が1件でも
ずれたらパス解決の失敗を疑う。

## やらないこと

- `sync-assets.sh` の変更（`.claude/` 配下をそのままコピーするため不要）。
- `tests/test_external_command_server.sh` を指す記述の更新（このリポジトリに実在せず、
  移動していないため）。
