# 【実装】【テスト】`get_branch_work_files` の改名対応

全体作業計画: `plans/rename-aware-work-files.md`
対象issue: #115
フェーズ: 3〈作業〉（flow-id 3-1）

種別を併記する理由: テストは実装と同時に書き、**1回の合意でまとめて判断できる**粒度のため
（`.claude/skills/issue-mr-flow/SKILL.md`「種別を複数併記する場合／分ける場合」）。

## 前提（確定済み）

- 修正対象は `.claude/scripts/src/vcs/Provider.sh` の `get_branch_work_files` の**未コミット分**のみ。
  コミット済み分（`git diff --name-only`）は改名を新パス1件として返すため触らない（issue #115本文）。
- 削除されたファイルの扱いは変更しない（同上。スコープ外）。

## 実装方針

### 1. `--porcelain -z` へ移す

行単位の `--porcelain` は、改名を `R  <旧パス> -> <新パス>` の1行として出力する。**パス自体が
` -> ` を含みうる**以上、区切りを一意に決める方法が無く、後段でどれだけ丁寧に分解しても曖昧さが
残る（さらに、空白を含むパスはダブルクォートで囲まれるため、アンクォート処理も必要になる）。

`--porcelain -z` は改名エントリを `XY <新パス>\0<旧パス>\0` の**2フィールド**として出す
（行単位形式とは順序が逆で、新パスが先）。NUL区切りのためクォートも行われない。フィールド境界が
曖昧にならないので、こちらへ移す。

### 2. 分解を純粋関数へ切り出す

`porcelain_z_to_paths`（標準入力 → 1行1パスを標準出力）を新設する。

- gitを起動しない純粋関数にすることで、`.claude/scripts/test/test_vcs_provider.sh`
  （外部コマンド呼び出しを伴わない単体テスト）の対象にできる。
- NUL区切りの読み取りは `while IFS= read -r -d ''` で行う（コマンド置換はNULを保持できない。
  `.claude/rules/shell-script-style.md`「コマンド置換とNULバイト」）。この関数がNULを吸収して
  改行区切りへ変換するため、**呼び出し側は従来どおり `$(...)` で結果を受け取れる**
  （`get_branch_work_files` の後半のロジックを変えずに済む）。
- 改名・コピーの判定は2桁のステータスで行い（`[RC]?` / `?[RC]`）、該当する場合のみ直後の
  旧パスフィールドを読み捨てる。未追跡（`??`）を誤って改名と判定しないこと。

### 3. `-c core.quotepath=false` は維持する

`-z` では元から影響を受けないが、同じ関数内のコミット済み分（`--name-only`、行単位出力）には
引き続き必要。両方に付けたまま揃える（受け入れ条件3）。

## テスト方針

`.claude/scripts/test/test_vcs_provider.sh` へ、`git status --porcelain -z` の出力を模した
フィクスチャによる単体テストを追加する。フィクスチャはNULを含むため、bashの文字列（`$'...'` は
NULを保持できない）ではなく `printf` で都度書き出す。

| # | ケース | 期待 |
|---|---|---|
| 1 | `R ` / `RM` / ` M` / `A ` / ` D` / `??` を混ぜた一覧 | 改名は新パスのみ、他は従来どおり |
| 2 | 同上 | 出力に `" -> "` を含む行が無い |
| 3 | 非ASCIIパス（`plans/【調査】新.md`） | 8進エスケープされずそのまま返る |
| 4 | 未ステージ側の桁の改名（` R`） | 新パスが返る |
| 5 | コピー（`C `） | 新パスのみ返り、次のエントリを食わない |
| 6 | パス自体が ` -> ` を含む改名 | 新パスが正しく返る（行単位形式では不可能） |
| 7 | 未追跡が2件連続（`??` `??`） | 2件とも返る（改名扱いして食わない） |
| 8 | 空入力 | 何も出力しない |
| 9 | 旧パスのフィールドが欠けた壊れた入力 | 無限ループせず、読めたところまでを返す |

## 検証手順

```bash
bash -n .claude/scripts/src/vcs/Provider.sh
bash -n .claude/scripts/test/test_vcs_provider.sh
bash .claude/scripts/test/test_vcs_provider.sh          # passed=N failures=0
```

**実機確認（合成フィクスチャだけで完了としない。`.claude/rules/shell-script-style.md`「テスト」）**:
一時リポジトリで実際に `git mv`（ASCII・日本語・` -> ` を含む名前）を行い、
`git status --porcelain` と `--porcelain -z | porcelain_z_to_paths` の出力を突き合わせる。
あわせて本リポジトリで `get_branch_work_files` を実行し、改名が無い状態の出力が従来と一致することを
確認する（受け入れ条件5）。
