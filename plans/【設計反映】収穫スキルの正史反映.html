DDR i0027-02

実測（bash 5.2.21）を2機構で記録: (1) サブシェルは条件文脈で errexit 一時停止が内側へ伝播（条件文脈の外なら fail-fast する）、(2) コマンド置換は inherit_errexit 既定オフのため条件文脈に関係なく -e を継承しない。採用: フォークされる側の内側で set -e を掛け直す2形（出力を捨てる ( set -e; f ) と出力を受け取る out="$(set -e; f)"）。却下: shopt -s inherit_errexit（bash 4.4 未満で使えない・既存コードへの副作用が広い・機構1に効かない）、set -E＋trap ERR（条件文脈で抑止され機構1を解決しない）、全コマンドの個別検査（漏れやすい）。
