検出スクリプトの設計（reportsの「検出方式の設計」節を実装する）

  1. 対象ファイル: git ls-files -z -- '*.md' '*.sh' '.gitignore'で取得 （バイナリを除く）。
  2. .claude/scripts/test/配下は除外する（フィクスチャに架空パスを含むため。 偽陰性のトレードオフはreportsに記録済み・設計判断として許容する）。
  3. Markdownコードフェンス（```で囲まれた範囲）内の行は除外する（行単位の 状態追跡が必要なため、ファイルごとにwhile readでbash内蔵処理として読み込み、 外部コマンドを呼ばない設計にする）。
  4. 正規表現\.claude/docs/ddr/i[0-9]+-[0-9]{2}-[終端文字を除く任意文字]*\.mdで 候補パスを抽出する。終端文字は空白・タブ・) ] " ' ` (とする（reportsの「既知の限界」で 指摘されたタブを追加する）。.mdで終わることを要求し、貪欲マッチ （bashの[[ =~ ]]は既定で貪欲）で最後まで一致させる。
  5. 抽出したパスに...または…（省略記法）が含まれる場合は 除外する。
  6. 残った候補について[[ -f "$path" ]]で実在確認する。存在しなければ 参照切れとしてfile:lineno:path形式で標準出力へ報告し、件数を返す。
  7. 実行タイミングは手動実行のみとする（.claude/rules/shell-script-style.md 「外部プロセス起動のコスト」に照らし、頻度の低い整合性チェックをhookへ組み込む価値は 無いという全体作業計画の判断を踏襲。将来resolve-conflictスキル等への合流が 必要になれば別issueで検討する）。

実装上の注意（shell-script-style.mdへの適合）

  • git ls-files -z + xargs -0またはwhile read -r -d ''で NULバイトを保持し、日本語パスのクォート化を回避する。
  • ファイルごとのgrep個別起動は避け、可能な範囲で xargs -0 grep -noEにまとめる（コードフェンス除外だけは行単位状態が要るため、 対象ファイルを1回< "$file"で読み込むbashループとする）。
  • git ls-filesはindexの内容を返すため、削除済み未ステージファイルが 混ざりうる。読み込み前に[[ -f "$path" ]]のガードを挟む。
  • スクリプト冒頭でset -euo pipefailを宣言し、BOM無しUTF-8・LF改行で保存する。

単体テストの設計

  • 対象は副作用の無い純粋ロジック（パス抽出の正規表現、3フィルタの判定）。
  • 少なくとも次のケースを含める:
    • 通常のDDRパス参照が実在すれば検出されない
    • 存在しないDDRパス参照は検出される（.gitignoreの元の2箇所相当の 再現ケース）
    • .claude/scripts/test/配下のパスはフィルタで除外される
    • コードフェンス内のパスは除外される
    • 省略記法（.../…）を含む候補は除外される
    • ファイル名自体に.mdを含むDDR（i0032-01-...Default.mdを正とし...md 相当）が貪欲マッチで正しく終端まで一致する
    • タブ区切りで2つのパスが同一行に並ぶ場合、2つの独立した候補として抽出される （既知の限界の修正を検証する）
  • bash -n構文チェックを行い、passed=N failures=N形式で出力、 失敗時は終了コード1。

やらないこと（スコープ外）

この計画では決めない・触らない
  • 相対パス表記（../docs/ddr/…）への対応（reportsの「確かめられなかったこと」 で見送りと記録済み）
  • 旧形式（4桁連番、i接頭辞なし）DDRパスの検出（本リポジトリに現存しないため。 将来配布先で必要になった場合の課題としてreportsに記録済み）
  • パスを伴わない裸のDDR識別子表記の検出（全体作業計画・個別調査計画でスコープ外と 合意済み）
  • 検出スクリプトのSessionStart/PostToolUse hookへの自動組み込み（全体作業計画で 「作らない」と明記済み）
  • 終端文字集合への全角読点（、）追加（reportsで「実例が無いため優先度を 下げる」と記録済み）

grep -noE '\.claude/docs/ddr/i[0-9]+-[0-9]{2}-[^]) "'"'"'`(\t]*\.md' .gitignore \
  | while IFS=: read -r lineno path; do [[ -f "$path" ]] || echo "$lineno:$path"; done
