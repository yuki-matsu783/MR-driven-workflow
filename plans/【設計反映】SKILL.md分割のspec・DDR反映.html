検証手順

分岐点は base="$(git merge-base origin/main HEAD)" で固定する（引数なしの git diff はコミットした瞬間に保証が失効するため使わない）。

#内容合格条件（実行するコマンド）
1specの変更行の節対応付けgit diff "$base" -- …/issue-mr-workflow.md の全ハンクが「コンポーネント構成」「セッション開始時の自動コンテキスト注入」「影響範囲の issue #160 エントリ」のいずれかに属する。既存エントリの削除・変更行0
2.claude/ 全体の巻き添え確認git diff "$base" --stat -- .claude/ が想定ファイルのみ。git diff "$base" -- .claude/docs/ddr/ の差分が「i0160-01 新規」と「i0113-01 の note 行」のみ
3DDR識別子の形式^i[0-9]{4}-[0-9]{2}- に一致し、title・H1 と一致
4DDR一覧の再生成generate-ddr-list.sh --check の終了コードが0。git diff "$base" -- .claude/docs/README.md に i0160-01 行と i0113-01 の注記変化が現れる
5全テスト16本すべて failures=0（合計 passed を記録）
6frontmatter検索search-frontmatter.sh --type ddr 相当で i0160-01 が引ける
7md/html同期（機械）md の ## 一覧と html の <h2> 一覧が一致・プレースホルダ0件・外部参照0件
8VERSIONの形式.claude/VERSION が 0.3.0 の1行のみ
