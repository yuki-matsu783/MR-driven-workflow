# 【設計】issue-mr-flow適用要否の判定基準の一元化

対象: issue #22。判定基準（ごく小さな変更の定義・除外条件）の一次情報を`AGENTS.md`に集約し、
`.claude/skills/issue-mr-flow/SKILL.md`・`.claude/rules/git-workflow.md`は参照のみに変更する。
全体作業計画（`plans/iterative-dreaming-yao.md`）参照。

## 変更差分

### 1. `AGENTS.md`（13行目、一次情報として拡充）

変更前:

```
- 開発フロー全体（issueの起票〜マージ）は `.claude/skills/issue-mr-flow/SKILL.md` を参照する
  （唯一の実装フロー定義）。ごく小さな変更を除き、全タスクはissueを起点に進める。
```

変更後:

```
- 開発フロー全体（issueの起票〜マージ）は `.claude/skills/issue-mr-flow/SKILL.md` を参照する
  （唯一の実装フロー定義）。**誤字修正・軽微なドキュメント修正等、フロー自体を省略してよい
  ごく小さな変更を除き、全タスクはissueを起点に進める**（除外時はmainへの直接コミットも
  許容する。ブランチ運用の詳細は `.claude/rules/git-workflow.md`「適用範囲」参照）。
```

判定基準の実体（「ごく小さな変更」＝誤字修正・軽微なドキュメント修正等の例示、および除外時の
帰結＝main直接コミット許容）をここに集約する。

### 2. `.claude/skills/issue-mr-flow/SKILL.md`（10-15行目、参照のみに変更）

変更前:

```
このファイルは `.claude/docs/spec/issue-mr-workflow.md` の実装であり、このプロジェクトにおける
**issue起票からマージまでの唯一のフロー定義**である。新機能追加・既存動作の変更など、
ごく小さな変更（誤字修正等。`.claude/rules/git-workflow.md` 参照）を除くあらゆるタスクは、
このファイルの手順で進める。
```

変更後:

```
このファイルは `.claude/docs/spec/issue-mr-workflow.md` の実装であり、このプロジェクトにおける
**issue起票からマージまでの唯一のフロー定義**である。適用要否の判定基準（除外してよい
「ごく小さな変更」の定義）は `AGENTS.md` を参照する。対象となるタスクは、このファイルの
手順で進める。
```

`description`（frontmatter）はSkill選択に使う実キーのため変更しない
（`.claude/rules/markdown-frontmatter.md`「対象外・特殊対応ファイル」）。

### 3. `.claude/rules/git-workflow.md`「適用範囲」節（16-19行目、判定基準を削り帰結のみ残す）

変更前:

```
## 適用範囲

`.claude/skills/issue-mr-flow/SKILL.md` の全体フローが適用されるタスク（新機能の追加・既存動作の変更）に適用する。
誤字修正・軽微なドキュメント修正等、フロー自体を省略してよいごく小さな変更は、mainへの直接コミットも許容する。
```

変更後:

```
## 適用範囲

適用要否の判定基準は `AGENTS.md` を参照する。フロー対象外と判定された変更（誤字修正・軽微な
ドキュメント修正等）は、mainへの直接コミットも許容する（本節は判定基準そのものではなく、
フロー対象外時のブランチ運用上の帰結のみを記載する）。
```

`alwaysApply: true`を持つため、frontmatterの既存キー（`alwaysApply`/`title`/`type`/
`description`/`tags`/`keywords`）は変更しない（`.claude/rules/markdown-frontmatter.md`
「対象外・特殊対応ファイル」）。

## 意味内容が変わらないことの確認

| 項目 | 変更前 | 変更後 |
|---|---|---|
| 除外対象の定義 | 「誤字修正・軽微なドキュメント修正等」（git-workflow.mdのみに実体あり） | 同じ文言、AGENTS.mdに実体を集約 |
| 除外時の帰結 | mainへの直接コミット許容（git-workflow.mdに実体） | 同じ、git-workflow.mdに「帰結」として残す（AGENTS.mdにも簡潔に言及） |
| 対象タスクの扱い | 除外以外はissue-mr-flow必須（SKILL.md・AGENTS.mdに重複） | 同じ、SKILL.mdはAGENTS.md参照に一本化 |

## 検証方法

1. 変更後の3ファイルを通しで読み、上表の意味内容が変わっていないことを確認する。
2. 「誤字修正」「軽微なドキュメント修正」という例示文言が`AGENTS.md`にのみ存在し、
   `SKILL.md`・`git-workflow.md`には存在しない（参照リンクのみ）ことを`grep`等で確認する。
3. `bash .claude/scripts/src/extract-frontmatter.sh .` を実行し `index.jsonl` 群を更新する。
