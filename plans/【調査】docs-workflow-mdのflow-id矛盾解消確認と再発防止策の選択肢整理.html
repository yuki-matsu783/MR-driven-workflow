この計画で何をするか

issue #143の受け入れ条件を満たすため、(a) issueが報告したreports/行のflow-id矛盾が 現在も残っているかを最終確認し、(b) 「再発防止策の要否を検討し記録する」ため、再発防止策の 選択肢を整理する。

変更対象

ファイル操作何をするか
.claude/rules/docs-workflow.md読み取りのみflow-id記述の現状確認（本計画では変更しない）
.claude/skills/issue-mr-flow/SKILL.md読み取りのみflow-idテーブルとの突合
.claude/docs/ddr/i0112-01-…md読み取りのみ既存の機械的検知見送り方針の確認
reports/…_調査.md（新規）新規調査結果の記録先

方針

まず(a)矛盾の現状確認を、`docs-workflow.md`全文の`flow-id`言及箇所の横断grepと、SKILL.mdの 正テーブルとの突合、およびgit履歴の確認で行う。次に(b)再発防止策について、機械的検知スクリプトの 新設・手順明記＋DDR記録・現状維持の3案を、実現コストと実効性の軸で比較する。

やらないこと（スコープ外）

この計画では決めない・触らない
  • .claude/docs/spec/ .claude/docs/ddr/の過去changelog・DDR本文の 書き換え（issue #143の受け入れ条件）
  • 再発防止策の実装そのもの（判断はフェーズ3〈作業〉へ送る）

検証

grep -rn "flow-id 5-1\|flow-id 5-3" .claude/rules/docs-workflow.md
git log --oneline -p -- .claude/rules/docs-workflow.md

合格条件: 片付けの意味を持つ古いflow-id記述（5-1/5-3）が現行記述として残っていないことを 確認できる。再発防止策の選択肢が最低3案、比較材料付きで整理できている。
