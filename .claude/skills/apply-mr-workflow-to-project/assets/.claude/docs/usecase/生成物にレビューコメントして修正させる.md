# 生成物にレビューコメントして修正させる

## どんな場面か

AIが作った計画・調査結果・実装に、直してほしい箇所がある。チャットで逐一伝えるのではなく、
PR/MRのレビューコメントとして該当行へ指摘を残し、AIにまとめて対応させたい場面。
このフローの各フェーズにあるレビュー往復（計画レビュー・結果レビュー）はすべてこの形で回る。

## 使う機能と流れの概要

- 人間はPR/MRの該当行へ普通にレビューコメントを書く。書き終えたらAIへ「レビュー完了」を伝える。
- AIは `/issue-mr-flow comments` で未解決コメントを取得する。出力には指摘行前後のソーススライス
  （指摘時点の断面）が付くため、コメントが書かれた後にコードが進んでいても、何への指摘かを
  取り違えずに修正できる。
- 修正後、AIは `/issue-mr-flow reply` で各スレッドへ対応内容を返信する。対応しない判断をした
  指摘にも理由を返信し、返信を省略してよい類型は作らない。チャットで受けた判断もMRへ記録される。
- スレッドの解決（resolved）はレビュアー側の操作として残る。往復は合意まで繰り返す。

## 何が得られるか

- 指摘→修正→返信の対応関係がスレッド単位でMRに残り、「どの指摘をどう扱ったか」を後から
  追跡できる。
- 未解決コメントだけを機械的に取得するため、対応漏れが構造的に起きにくい。
