# worklog: manifest方式の実装

対象: issue #26 フェーズ3（2026-08-22）。push回数: 9。
結果の正文: `reports/20260822_ai-asset-manifest-distribution_manifest方式の実装結果.md`

## 試したこと

- 層分け定義 → 網羅性チェック → `.gitignore` のマーカー化 → 小さいスクリプト（`cleanup-task`・
  `collect-review-points`・`setup-gemini-links`）→ インストーラ、の順で作った。
  **依存の下から積む**と、上を書く時点で下が実際に動いているので、失敗の切り分けが早い。
- 各段階で**すぐ流した**。書き終えてからまとめて流していない。

## うまくいったこと

- **`.claude` を広く `core` にして例外を後ろに2つ置くだけ**で、`.claude/` 配下の分類が閉じた。
  副次的に、この作業で新しく追加した7ファイル（定義・チェッカ・雛形2件・テスト2件・
  `agent-common.md`）が**自動的に被覆された**。敵対的レビューは「新規追加ファイルの層が
  未定義」を指摘していたが、last-match-wins の広域エントリという形にした結果、
  1件ずつ列挙する必要がそもそも無くなった。
- **`json-keys` で「値が配列なら和集合、それ以外は全置換」という1つの規則**にしたら、
  `permissions.deny`（和集合が要る）と `hooks`（全置換が要る）の両方が満たせた。
  キーごとに振る舞いを書き分ける必要が無い。
- **実体コピーの同期で `.gemini/<name>` 自体を消さない**設計にしたのが効いた。テストで
  「`.claude/` 側が無傷であること」を表明できるのは、消す対象を中身に限ったからである。
  加えて「物理パスが同一なら触らない」安全網も入れた（symlinkは確実に弾ける）。

## ダメだったこと

**7件の不具合を作り、すべて「実際に流したこと」で見つけた。** 内訳は結果レポートの表にある。
ここには、同じ失敗を繰り返さないための観察だけを書く。

- **リポジトリ規約に明記のある罠を、3つも踏んだ。**
  - 生の制御文字をソースへ書かない → **3箇所書いた**（`\u001f` と書いたつもりが実体で入った）。
    さらにこのworklog自身を書くときにも同じことをやり、Bashツールが
    「コマンド文字列に非表示の制御文字が含まれる」として弾いた（**規約が予告していたとおりの
    形で表面化した**）。
  - `git grep` の `core.quotepath` → 検証コマンドで踏んだ（40件 vs 3件）。
  - 先頭がハイフンの値 → `printf '--allow-dirty …'` で踏んだ（規約は `jq`/`grep` の例だけを
    挙げているが、**`printf` でも同じことが起きる**）。

  **規約を読んでいることと、書くときに思い出すことは別である。** 特に制御文字は、
  diffにも `grep` にも見えないので、**バイト数比較の検査を機械的に流すしかない**。
  今回はスクリプト3本とレポート1本の計4ファイルで検査し、2ファイルで実際に見つかった。

- **タブを区切りにして列がずれた。** 「`read` はIFS空白文字の連続を畳む」というのは
  bashの基本仕様だが、`@tsv` という便利な出力があるとつい使ってしまう。
  **空になりうる列がある表形式は、タブで区切らない。**

- **CRLF配布先での冪等性を、作り直しで再発させた。** これが一番重い。旧実装が既に直していた
  欠陥（issue #33 の #1）を、新実装で作り直した。**受け入れ条件（issue #26 の1〜11）には
  この挙動が1つも現れない**ため、条件だけを見てテストを書いていたら無言で退行していた。
  計画段階で「現行テストが持つ、受け入れ条件に現れない保証」を棚卸ししていたことが、
  そのまま回帰テストとして効いた。

- **自分で書いた検証コマンドが、2回続けて「検出できないのに通る」形だった。**
  1回目は敵対的レビューの反映時（push8）、2回目は網羅性チェックのプローブ配置
  （`.claude/` 配下に置いて広域エントリに被覆された）。**「検出できることを確かめる」検証は、
  検証自体が正しいかをもう一段確かめないと意味を持たない。**
  テストへは「意図的に壊して落ちること」を4種すべてについて入れた。
