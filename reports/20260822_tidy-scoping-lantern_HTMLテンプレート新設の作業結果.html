確かめられなかったこと

この結果が言っていないこと
  • Windows（git bash）実機での確認は行っていない。 すべて Claude Code on the web の Linux環境で行った。HTMLの表示・grep の挙動はプラットフォーム非依存だが、ユーザーの常用環境での見た目は確認できていない。
  • CDN方式との見た目の比較はできない。 この環境は外部通信が遮断されており、TailwindCSS CDNを読む形のHTMLは1度も表示を確認できない。「自己完結CSSとCDN版のどちらが読みやすいか」は比較していない。
  • 人間のレビューを受けていない。 非対話セッションのため flow-id 3-3/3-4/3-8 の人間レビューは adversarial-review スキルで代替している。テンプレートの「読みやすさ・使いやすさ」という主観的な品質は、この代替では検証できていない。
  • 全体作業計画（flow-id 1-4）へテンプレートを適用した実例が無い。 遡って作らない方針にしたため、[全体作業計画のみ必須] の2セクションが実運用で過不足ないかは、次のissueで初めて確かめられる。

想定と異なった点

計画時の見込み実際どう扱ったか
テンプレートを自分の計画へ適用すれば、実地検証として十分 テンプレート自身の欠陥が出た。埋め忘れ検査が、地の文の「ここに書く」を誤検知した 検査を <!-- 込みへ改め、6箇所を揃えた。テンプレートを説明する成果物は、そのテンプレートにとって最悪の入力になる
「自己完結」は https:// を含まないことで検査できる 2つの意味が混ざっていた。「外部を読みに行かない」と「URLを1文字も含まない」は別物で、後者では http://www.w3.org/2000/svg で必ず落ちる 検査を前者だけに限定した
