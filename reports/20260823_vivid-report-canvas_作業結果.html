実施した内容と結果

1. 節の並び順の変更と「重点レビュー依頼」の新設 ◎良

節順を「目次 → 重点レビュー依頼 → サマリ（結論の一覧） → 確かめられなかったこと → 実施条件（測った対象・環境） → 実施した内容と結果 → 設計への反映 → 想定と異なった点 → 残課題」へ変更した。節名は1つも変えていない（調査結果Q1の「節名全維持」どおり）。

id="review-focus" の必須節を新設。3段階（◆特に見てほしい／◇承認が欲しい／・細かいレビューは不要）を .focus.must/.want/.skip のカードで表現し、重みは色相ではなくアクセント系1色相の濃度（--accent-soft 地／--panel 地）・枠の太さ（2px／1px）＋記号で表す。第3段階は --line 枠＋ --muted 文字（背景には使わない）。

結論 検証6（h2の実測と期待9行のdiff）は差分なし。本レポート自身がこの節順で書かれている。

2. サマリの結論カード化と色トークン・チップ ◎良

サマリの表を廃止し、結論カード（ol.verdicts > li.verdict）へ置き換えた。1カード＝性質チップ＋結論1行＋根拠の性質（旧表の4列目を引き継ぐ）＋該当章リンクの4要素。ヘッダ帯には結論件数チップ（p.counts）を追加した。

:root へ --good: #1d4ed8; --good-soft: #e7edfd;、ダーク側へ --good: #8ab4f8; --good-soft: #17233a; を追加。.tag 基底＋色修飾子の4行（旧144〜147行）を削除し、.chip 基底＋ .chip.good/.warn/.stop の4行を追加した（旧 .tag.* の利用箇所が本体マークアップに無いことを確認済み）。

結論 --ok（緑）と .box.ok は「決めたこと・手順の成功」専用として存続させ、役割分担をCSSコメントと冒頭コメント「色・記号の使い分け」へ明記した。

3. 「確かめられなかったこと」の前半移動と詳細callout ◎良

一覧をサマリ直後へ移動。1行1件で全項目を挙げ、各行から関連章へリンクする形にした（節名・--warn の警告色は維持）。各章側に .box.warn.unverified-detail（ラベル「確かめられなかったこと（詳細）」）の見本を置いた。

結論 「一覧側を空にして詳細だけを章へ書かない」分担を節コメントへ明記した。本レポートの章5がこの分担の実例になっている。

4. アンカーの位置ずれ対策とリンク破断検査の伝承 ◎良

section[id], h3[id] { scroll-margin-top: 16px; } を追加し、「実施した内容と結果」の h3 に id="f1" 連番を振って見出し隣に性質チップを置く見本を収載した。冒頭コメントへリンク破断検査（comm -23、出力0行が合格）と、# を &#35; と書くエスケープの適用範囲（具体的なIDを引用する見本アンカーのみ。検査コマンドの正規表現には適用しない）を明記した。

結論 検証2（本体の破断なし）は出力0行、検証2b（意図的破断の検出）は zzz-broken 1行を検出した。
