# 全体作業計画: HTMLスライド作成スキル・テンプレート・サブエージェント2本の追加

- ブランチ: `claude/html-slide-skill-template-ymue7k`（ハーネス指定。`.mrworkflow.json` の
  `feature-{issue}-{slug}` 命名とは異なるが、実行基盤（Claude Code on the web）がこのブランチでの
  開発を指定しているため、ハーネス側の指示を優先する）
- PR: #194（Draft）
- 作成日: 2026-08-23

## この計画で何をするか

調査結果・設計内容・issue対応の報告を**投影して発表するスライド**の形で残せるように、次の4点を
追加する（issue #168「期待する動作」）。

1. **スライドテンプレート1本**: `.claude/skills/<スキル名>/assets/slides.template.html`。
   自己完結（CDN・外部フォント・外部画像なし）で、スライド型8種（表紙／章扉／箇条書き／2カラム／
   図解／表／比較／まとめ）、キーボード（←→／Space／Home／End）とクリックのページ送り、進行表示、
   `@media print` による1スライド1ページのPDF化を持つ。
2. **スキル1本**: `SKILL.md` が「テンプレートをコピー → 型を選ぶ → 穴を埋める →
   プレースホルダ残存チェック」の手順を定義する。見出し構成の正はテンプレート側に置き、再掲しない。
3. **サブエージェント2本**: ①構成設計（読み取り専用。構成案をJSONで返す。HTML生成はしない）／
   ②HTML生成（渡された構成に忠実に埋める。構成の再設計はしない。食い違いは差し戻す）。
4. **構成案JSONのスキーマ定義**: 将来の .pptx 書き出し（別issue）の入力にできる機械可読な形。

## 進め方（非対話セッションでの運用）

本セッションは Claude Code on the web のリモート実行環境で、人間のレビュー往復を待てない
**非対話セッション**である。ユーザーの明示指示により、次の運用で進める。

- **各フェーズの計画をpushした直後に敵対的レビューを1回**、**作業実施をpushした直後に1回**、
  自動起動する（`adversarial-review` スキル。非対話セッションの自律起動は同スキルが許可している。
  各フェーズ上限3回の範囲内）。
- 指摘への対応・修正を行い、対応内容を各スレッドへ返信してから次のステップへ進む。
- 人間担当のレビューステップ（2-3/2-8/3-3/3-8/4-3/4-8等）は実施できないため、該当ループ範囲の
  進捗記号は `[]` のまま残し、実施した内容は HANDOFF.md「やったこと」の文章で補足する
  （`.claude/rules/docs-workflow.md` の非対話的実行環境の扱いに従う）。
- 全体作業計画の人間合意（flow-id 1-5）も同様に待てないため、ユーザーの当初指示
  （「PR作って進めて」「敵対的レビューを自動で行い修正しながら進めること」）を包括的な承認として
  進め、計画自体もPR上でレビュー可能な形で残す。

   ダークモード対応はどう作られているか。`slides.template.html` が踏襲すべき点はどれか。

   `issue-mr-resume.md` のfrontmatter（`description` はClaude Codeが実際に使う）・本文構成・
   ツール制限の書き方はどうなっているか。
3. **スキル名**: 既存スキル（`canvas-report` 等）との整合が取れる名前は何か。
4. **出力先ディレクトリの既定**: `wip/reports/` は flow-id 5-5 で削除される寿命。スライドを
   タスク成果物として残す場合／恒久に残す場合の選択肢を洗い、既定を確定する（issue #168
   「期待する動作 4.」の指定事項）。
5. **構成案JSONスキーマの置き場所と形式**: スキル配下のどこに置くか（`references/` か
   `assets/` か）。検証手段（jq等）をどう示すか。
6. **配布・同期への影響**: `dist-layers.json` の層分け・`check-dist-coverage.sh` の検査・
   `sync-gemini-assets.sh` の変換同期・`index.jsonl` への載り方に、新規ファイルがどう影響するか。
7. **ドキュメント追記先**: `.claude/rules/directory-structure.md` のツリー・
   `.claude/rules/markdown-frontmatter.md` の type 表への追記要否。
