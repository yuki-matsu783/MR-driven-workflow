反映内容

「JSON操作」節（既存の//falsy化の項の直後、節の末尾）へjq優先順位の項目を追記する。 「エラー方針」節（pipefailの説明の後）へgrep -oの項目を追記する。いずれも追記のみで、既存記述の 置き換えは無い。

追記する主張は実行して検証済み 「悪い例」jq -n '{counts:[]} | type == "object" or has("counts") | not' → false、 「良い例」jq -n '{counts:[]} | (type == "object") or (has("counts") | not)' → true をjq 1.7で実測し、説明と一致することを確認済み。

検証

# 追記する主張そのものが正しいことを実行して確かめる
jq -n '{counts:[]} | type == "object" or has("counts") | not'          # => false（悪い例）
jq -n '{counts:[]} | (type == "object") or (has("counts") | not)'      # => true（良い例）

# grep -oのpipefail依存中断を実行して確かめる
bash -c 'set -e;        f(){ local s; s="$(printf "no match\n" | grep -o "XYZ" | tail -1)"; echo "reached rc=$?"; }; f'
bash -c 'set -eo pipefail; f(){ local s; s="$(printf "no match\n" | grep -o "XYZ" | tail -1)"; echo "reached rc=$?"; }; f'; echo "outer=$?"

# 追記が入ったことを、変更前に0件だった語で確認する
