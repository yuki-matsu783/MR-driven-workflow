### 1. DDR `i0145-01`（案Bの判断）を作る

`.claude/docs/ddr/i0145-01-MR_PRテンプレートを見出し構成の唯一の正としdescribeが読む.md`

- **決めたこと**: `.github/pull_request_template.md` を見出し構成の唯一の正とし、
  `describe` はそれを読む。GitLab版は複製で、先頭コメントを除いた全文差分が空であることを
  テストで固定する。
- **却下案**: 案A（`describe` 節を正としテンプレートを生成する）／案C（両方に書いて一致検査）。
- **あわせて記録すること**:
  - `.github` / `.gitlab` の配布層を `core` のまま変えなかった理由。
  - Draft PR初期本文を10節に合わせない理由。
  - **記入ガイドを両側から同時に消しても検査を素通りした**という実測（検査 (a2) の存在理由）。

### 2. DDR `i0145-02`（#111 との役割分担とdescriptionの最終形）を作る

`.claude/docs/ddr/i0145-02-MR_descriptionと統括レポートのサマリコメントは併存させる.md`

- **決めたこと**: 併存させる。分ける軸は**自動処理が繰り返し上書きするか（description）／
  1回きりか（サマリコメント）**という非対称である。
- **限界を必ず書く**: 根拠は**このリポジトリの自動化経路**（`Provider.sh` に投稿済みコメントを
  編集する関数が無い）であって、**GitHub/GitLab の外部APIの性質ではない**。
- **`describe` を 5-4 の後に追加しない**という却下と、その2つの理由もここへ書く
  （事実側の「最終形は 4-10」は spec 側。作業項目4）。
- **却下案**: サマリコメントを廃止して description へ一本化する／サマリコメントを description
  へのリンク1行にする。
- **1件にまとめるか2件に分けるか**: **分ける**。片方だけが後から supersede されうる独立した
  判断であり、1つにまとめると `status` を付けられない。

### 6. `.claude/VERSION`（人間の判断で 0.4.0 据え置きに確定）

**⚠ 前提が2度変わった。** (1) main の PR #191 が VERSION を **0.4.0 へ上げた**ため、当初計画して
いた「0.3.0 → 0.4.0」は成立しなくなり、**0.4.0 → 0.5.0（MINOR）**へ訂正した。(2) その 0.5.0 を
適用した後、**ユーザーの判断で 0.4.0 据え置きに確定した**（下記）。

- **MINOR の根拠**: 目安表の「資産の追加・フローの拡張」に当たる。配布先に手作業を要求する
  非互換変更（配置場所の変更・必須スクリプトの引数変更）は無いので MAJOR ではない。
- **⚠ この項目は完了後にユーザーの判断で結論が変わった。** AIエージェントは非対話セッションの
  例外規定に基づき `0.5.0` をいったん適用したが、**ユーザーへ確認したところ「0.4.0で良い」との
  回答を得たため `0.4.0` へ戻した**（2026-08-23）。例外規定が定める「レビューで否認されたら
  元の値へ戻す」に従った結果である。
- **据え置いた事実は `distribution-assets.md` の `### issue #145` changelog と
  `HANDOFF.md`「判断を迷った内容」の両方へ残した**（「適用したが記録が無い」という第3の状態を
  作らないため）。

### 着手前に確かめること

- **完了条件5・6 は回帰ガードである**（作業中に一度偽になりうるので意味がある）。
  - 6 は**着手前から4件**ある（着手前SHA `c076fa2` を worktree へ取り出して実測）。
    これから作るDDR 2件を絶対パス形式で指している箇所が、**全体作業計画に2件・この個別計画自身に
    2件**あるため。**作業項目1・2の完了で0へ戻るのが正しい挙動**で、「作業前は4件・作業後は0件」を
    確かめる。**当初この欄を「2件」と書いていたが、全体作業計画だけを数えて自分を数え忘れていた**
    （敵対的レビューで実測により指摘。値そのものは結論を変えないが、この計画は冒頭で
    「着手前の実測値を併記する」と宣言しているので、測らずに書いた数字が混ざるのは趣旨に反する）。

  - **どちらも完了の根拠にはしない**（走らせはする。他の変更による回帰は拾えるため）。
