# push11: フェーズ4の反映を実施

`【設計反映】`（検証15項目）と `【AIアセット反映】`（検証6項目）を実施。**21項目すべて合格。**

## 教訓1: 仕様節だけを読むと、その後に積まれた個別の判断を見落とす

計画（決定B）は「VERSIONを `0.4.0`（MINOR）へ上げる」だった。根拠は
`distribution-assets.md` の `## 仕様` にある**非対話セッション例外**である。

しかし実施のために同じファイルを開いたところ、`## 影響範囲`「issue #165」（**本issueと同日**）の
末尾にこう書かれていた。

> 今後 `.claude/VERSION` を上げる場合は、**改めて人間の指示を起点に**増分を検討する。

計画の時点では「`## 仕様` が正で、`## 影響範囲` はその回の記録にすぎない」と解釈していたが、
**この一文は「その回の記録」ではなく、明示的に「今後」を対象にした指示**である。
`.claude/VERSION` に限定され、非対話例外より**後**に置かれている。**据え置きへ変えた。**

- **changelogは過去の記録だけを置く場所とは限らない。** 「今後は〜する」と書かれた行は、
  仕様節の一般規定を**狭める**。仕様節を読んで判断が付いたと思っても、同じファイルの
  changelogを最後まで見る。
- **提案（`0.4.0`）と根拠は捨てずに記録した。** 上げる指示があればそのまま適用できる。
- **据え置きの場合も、規定が義務づける2つの記録は同じように書いた。**
  「適用したが記録が無い」だけでなく「据え置いたが記録が無い」も避けるべき状態である。

## 教訓2: 参照切れ検査は、ドキュメント中の「コマンドの例示」も拾う

`check-doc-references.sh` が参照切れ1件を報告した。実体は、**計画に書いた検証コマンド**で、
`.claude/docs/ddr/` の下をファイル名のglob（`i0185-01-*.md`）で指していたものである。
同スクリプトは絶対パス形式の記述を拾うので、**glob を含むパスは必ず「存在しないファイルへの
参照」になる。**

```bash
# 検査に引っかかる（globは実在パスにならない）
ls .claude/docs/ddr/i0185-01-*.md
# 引っかからない（パスはディレクトリまで。ファイル名はgrepのパターン）
ls .claude/docs/ddr/ | grep -c '^i0185-01-'
```

**計画・レポート・worklogへコマンドを書くときは、パスにglobを含めない。** 検査を通すため
だけでなく、「本当に参照が切れている1件」がこの種のノイズに埋もれるのを避けるためでもある。

**この教訓を書いているこのworklog自身が、同じ形で参照切れを1件出した**（敵対的レビュー6回目の
指摘）。`check-doc-references.sh` の走査対象は追跡ファイル全体で、`wip/worklogs/` も含まれる。
**検査を回した後に書いたファイルは検査を通っていない**——検査は「反映が終わったあと」ではなく
**その回のコミットに入る全ファイルを書き終えたあと**に回す。なお**フェンス内のコードブロックは
除外される**ため、上のコード例は引っかからない。引っかかったのは地の文のほうである。

## 教訓3: hookの部分一致への縮退は、DDRを書いている最中にも起きる

DDRの「未計測」節で `create-commit.sh` の実装を説明するため、`git commit -m` という文字列を
含むヒアドキュメントをBashツールへ渡したところ、**コミットをブロックするhookに止められた。**

issue #53 で判定はコマンド位置ベースになったが、**この規模のコマンド文字列では部分一致へ
縮退する**（`.claude/rules/git-workflow.md` の既知のトレードオフ。1行8192バイト超）。

- **対処は2つとも行った。** (1) 長文ファイルの生成をWriteツールへ切り替える
  （`.claude/rules/shell-script-style.md` が元々「150行規模のヒアドキュメントは使わない」と
  定めている）、(2) 文面を「gitのコミットコマンドの `-m`」へ言い換える。
- **「判定がコマンド位置ベースになったから地の文は安全」と一般化しないこと。** 縮退の条件
  （長い行・`eval`・古いbash）はルールに明記されており、**長文ドキュメントの生成はその条件に
  当たりやすい。**
