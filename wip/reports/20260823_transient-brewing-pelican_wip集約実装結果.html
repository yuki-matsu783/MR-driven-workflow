実施した内容

1. KEEP_PATHSの動的化（cleanup-task.sh）

トップレベルのreadonly -a KEEP_PATHS=("worklog/TEMPLATE.md")を KEEP_PATHS=()（空配列・readonly外し）へ変更し、main()内で target_dirs読み込み直後にKEEP_PATHS=("${target_dirs[1]}/TEMPLATE.md") を代入する形にした。declareは使わず素の代入文にすることで、main()を 経由しない単体テストの直接呼び出しからも正しく見えることを確認した。

test_cleanup_task.shには、既存のis_keep_path直接呼び出し前への 明示セット行と、.mrworkflow.jsonでworklogDir: "wip/worklogs"を 指定する新規フィクスチャによる結合テスト2件を追加した（既存フィクスチャは .mrworkflow.jsonを持たずこの配線を一度も検証できていなかったため）。

Provider.sh・cleanup-task.sh:224のjqフォールバック既定値は 変更していない（.mrworkflow.jsonを持たない配布先が旧レイアウトのままである 前提を保つため）。

2. ディレクトリ移動

mkdir -p wipの後、移動先3つの非存在をif文で確認してから git mv plans wip/plans && git mv worklog wip/worklogs && git mv reports wip/reports を実行した。13件すべてがgit status上でR（rename）と認識されている。
